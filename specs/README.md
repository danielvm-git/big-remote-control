# Specs

All planning documents for Big Remote (bigpowers layout). Start at `state.yaml`.

| File | Answers |
|------|---------|
| `state.yaml` | Where are we? Next skill, workflow mode (`solo-git`). |
| `release-plan.yaml` | What ships next, in what order (WSJF, BCP baseline). |
| `execution-status.yaml` | Story status — the only source of truth. |
| `product/` | Scope, vision, glossary. |
| `tech-architecture/` | Stack, security, test plans. |
| `adr/` | Irreversible decisions and why. |
| `verifications/` | Evidence from real TVs. |
| `bugs/` | Bug specs and registry. |
