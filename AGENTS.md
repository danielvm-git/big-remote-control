## Project

Native macOS menu bar app that controls Samsung Tizen TVs (The Frame), Sony BRAVIA and LG webOS TVs directly over the local network.
Stack: Swift 6 / SwiftUI / macOS 15+ and iOS 18+ (`BigRemoteiOS`, ADR 0006), Xcode project generated by XcodeGen, Swift Testing.

## Observability

Both apps write a structured log: one JSON object per line (`ts`, `level`, `category`, `message`, `device`,
`tv`, `fields`), one file per day, 14 files kept, mirrored to `os.Logger` (subsystem `com.danielvm.BigRemote`).
Categories: app, pairing, link, command, poll, power, discovery, network.

| What | Command |
|------|---------|
| Follow the Mac log | `bash scripts/logs.sh mac` |
| Copy the iPhone log over USB | `bash scripts/logs.sh iphone` (dev-signed build, phone unlocked) |
| Pairing timeline, Mac + iPhone | `bash scripts/logs.sh pairing` |
| Where the logs are | `bash scripts/logs.sh path` |
| In-app | Mac: Settings > Diagnóstico; iPhone: TVs tab > Diagnóstico (Share) |
| Console.app | filter `subsystem:com.danielvm.BigRemote` |

When a TV asks to pair again, run `scripts/logs.sh pairing` first: `token.cleared` and `token.saved` carry the
`caller` (file:line) and the before/after fingerprints, so a token overwrite shows up as a changed fingerprint.

## Architecture

`AppModel` (main actor, split into `AppModel+*.swift` extensions) owns UI state and calls one `TVController` actor per TV:
`SamsungTVClient`, `SonyTVClient` or `LGTVClient`, picked by `TVDevice.brand` (ADR 0005).
`SamsungTVClient` drives the remote and art WebSocket channels; `TVRESTClient`, `WakeOnLANSender` and `SmartThingsClient` cover REST, WOL and the optional cloud path.

## Conventions

- `project.yml` is the source of truth. NEVER edit `BigRemote.xcodeproj`; run `xcodegen generate`.
- Wire formats live in `Services/Protocol/` and MUST stay pure (no I/O) so tests compile them without the app.
- Every protocol finding from a live TV MUST be recorded in `docs/PROTOCOL.md` § live test results.
- UI strings are pt-BR. Code, comments, commits and specs are English.
- Every connection, pairing step and command path MUST log through `Log.*` (`Services/Log.swift`); never `print` or `NSLog`.

## Never

- Never dismiss reproducible gate failures as pre-existing or out of scope
- Never proceed on red Preflight or red CI — invoke quick-fix or fix-bug first
- Never send `KEY_FACTORY` or automate menus near Factory Reset, Reset Smart Hub or DNS.
- Never log a token, PIN, cookie or client key. Log `LogRedactor.fingerprint(_:)`; `LogRedactor` also masks by field name.
- Never make the phone a requirement for a core feature.
- Never commit `build/`, `DerivedData/` or `BigRemote.xcodeproj/`.
- Never force-unwrap (`!`) in production paths without a documented invariant.

## Token Economy — Minimal Footprint

> Production-safe subset of the 8-rule AGENTS.md pattern (Vercel engineer, ~60B tokens).
> Rule 1 ("no backward compatibility") is excluded deliberately: it risks data loss in production.

1. **Check existing dependencies first.** DO inspect what your current dependencies already do before adding a package or writing your own code.
2. **Prefer mature, maintained libraries.** DO NOT rewrite a capability a maintained library provides without a documented reason.
3. **Copy validated patterns.** DO study how established products solve the same problem before inventing a new approach.
4. **Keep the simplest working implementation.** DO write the least code that satisfies the stated requirement. NEVER add preventive abstraction or unused config layers.
